# 顾客商品双手承托高度修复设计

## 目标

顾客播放 `idle2_NaHeZi` 或 `walk_NaHeZi` 捧物动作时，购买的整组木头或玉米应稳定显示在双手承托位置，不再整体偏低。

## 根因

当前运行时会读取左右手骨骼位置，并将商品组的底面对齐到左右手骨中点。手骨节点位于手腕附近，不等同于视觉上的掌心承托面，因此商品组虽然跟随双手，整体仍显得偏低。

## 行为

- 保留左右手 Socket 和双手中点跟随逻辑。
- 保留商品整体包围盒对齐，确保不同数量的木头和玉米作为一个整体移动。
- 在双手中点的世界高度上增加固定 `0.12` 单位的承托偏移。
- 森林区与玉米区、三套男顾客与两套女顾客共用该偏移。
- 不修改商品方向、商品堆叠间距、购买流程、捧物动作或顾客路径。

## 结构

在 `CustomerAppearanceRandomizer` 上新增可序列化参数：

```ts
@property public carryHeightOffset = 0.12;
```

运行时计算商品组位置时，垂直方向调整为：

```ts
this._carryPosition.y += (
    this._handCenter.y
    + this.carryHeightOffset
    - bounds.minY
);
```

横向和前后方向仍以商品包围盒中心对齐左右手中点。

## 异常处理

- 找不到商品渲染包围盒时维持当前帧位置，不影响购买与离场。
- 找不到左右手骨骼或动画组件时维持原有携带节点，不中断顾客逻辑。
- 偏移只作用于运行时随机顾客模型，不改写场景中商品库存坐标。

## 验证

- 男顾客和女顾客播放捧物待机时，整组商品显示在双手上方。
- 顾客播放捧物行走时，商品持续跟随双手且高度稳定。
- 木头和玉米均应用相同的 `0.12` 高度偏移。
- 商品数量变化时仍作为整体对齐，不拆散堆叠。
- 顾客购买、付款和离场逻辑保持不变。
