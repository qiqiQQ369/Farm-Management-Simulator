# 移除顾客表情功能设计

## 目标

彻底移除森林区和玉米区顾客头顶的完成表情功能，同时保留商品需求提示牌、购买流程和顾客其他行为。

## 范围

移除：

- 森林顾客 `emoji` 的检查、计时、显示和重置逻辑。
- 玉米顾客完成购买后创建、显示和重置 `emoji` 的逻辑。
- 顾客模型替换时对旧 `emoji` 子节点的保留规则。
- 顾客调度器中仅供表情使用的资源引用和辅助方法。

保留：

- 顾客头顶的商品需求提示牌 `fillTip`。
- 木头或玉米图标及所需数量。
- 顾客排队、购买、付款、携带商品和离场逻辑。
- 车辆的独立表情功能。

## 结构

### 森林顾客

`NPCScheduler` 不再维护表情状态，也不再在购买完成时激活 `emoji`。原有需求提示牌仍由 `fillTip` 独立控制。

### 玉米顾客

`CornCustomerScheduler` 不再根据 `completionEmojiFrame` 创建表情节点，也不再在购买完成或队伍重置时访问 `emoji`。

### 顾客模型替换

`CustomerAppearanceRandomizer` 仅保留购买链路所需的 `StoragePoint` 子节点。旧场景中的 `emoji` 会与旧视觉节点一起移除，避免遗留表情重新出现。

## 兼容处理

- 场景中即使仍存在旧 `emoji` 子节点，运行时模型替换也会将其清除。
- 不依赖场景手工删除节点，因此编辑器预览和网页 Release 行为一致。
- 不修改 `VehicleCollector`，车辆表情继续按原逻辑工作。

## 验证

- 森林顾客完成购买后不显示黄色表情。
- 玉米顾客完成购买后不显示黄色表情。
- 顾客等待、购买和离场过程中均不会重新激活 `emoji`。
- 商品需求提示牌仍正常显示和更新。
- 顾客仍能购买商品、产生金钱、携带商品并离场。
- 车辆表情逻辑保持不变。
