# 解锁镜头平移设计

## 目标

所有非田地解锁展示都不再瞬间切换镜头。镜头从主角当前位置平移到新解锁对象，到达后才开始对象的解锁展示动画，随后返回主角。

## 范围

- 森林区：伐木工、拖拉机、搬运工。
- 玉米区：工人、拖拉机、搬运工。
- 不修改田地区域解锁；`FinishNode` 的田地展示镜头保持现状。

## 统一时序

1. 解锁支付完成后锁定摇杆并停止主角移动。
2. 镜头保持当前角度和观察距离，用 `0.6` 秒从主角平移到目标对象。
3. 镜头抵达目标后才激活或启动该对象的现有解锁展示动画。
4. 镜头继续展示目标 `2.4` 秒。
5. 总计 `3` 秒后恢复跟随主角并解除摇杆锁定。

## 实现边界

- `CameraController` 提供唯一的解锁平移接口，负责计算目标镜头位置、暂停普通跟随更新、执行平移，并在到达时触发回调。
- `CoinConsumer` 和 `ResourceFieldSystem` 只负责提供目标节点、到达后的展示回调以及 3 秒结束时的控制恢复。
- 平移期间不改变镜头 Rotation、FOV、正交高度、跟随距离和边界配置。
- 新的解锁对象必须在镜头抵达后才开始其展示动画；业务激活所必需的创建和配置可以提前完成。

## 验收

- 六类非田地解锁镜头都能看见从主角到对象的连续平移。
- 对象解锁动画不会在镜头抵达前播放。
- 每次镜头锁定总时间仍为 3 秒。
- 田地解锁镜头表现无变化。
- Web Release 不依赖类名或编辑器专属行为。
